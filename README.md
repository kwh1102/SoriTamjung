# 소리탐정 — 사라진 소리를 찾아서

악기를 되찾으면 실제 전시품이 돌아오고, 장단을 복원하면 3D 장단판이 함께 울리는 국악 탐험 퍼즐 웹게임입니다. Three.js와 Web Audio로 실행하며 설치·회원가입·게임 중 생성형 AI 호출이 필요하지 않습니다.

## 실행

Node.js 22.12 이상에서:

```sh
npm ci
npm run dev
```

터미널에 표시되는 Local 주소로 접속합니다. 기본 주소는 `http://localhost:5173`입니다. 같은 Wi-Fi의 휴대폰에서는 Network 주소를 이용할 수 있으며 방화벽 설정에 따라 접속이 제한될 수 있습니다.

```sh
npm test
npm run build
npm run preview
```

`dist/`를 정적 호스팅에 올리면 음원까지 포함됩니다. `file://` 대신 HTTP 서버를 사용하세요. 이번 개편은 로컬 소스에 반영되어 있으며 기존 공개 사이트의 재배포는 별도입니다.

## 13개의 복원 과제

1. **악기 갤러리 · 6단계**: 3–5개 층의 완성 합주와 불완전 합주를 비교합니다. 아홉 악기의 음색과 전시 기록을 대조해 한 악기, 후반에는 두 악기를 동시에 찾습니다. 정답마다 비어 있던 진열장에 악기가 나타납니다.
2. **장단 공방 · 4단계**: 세마치·굿거리·자진모리·휘모리의 타격과 쉼을 복원합니다. 9·12·8칸 구조, 빨라지는 속도, 시작점이 이동한 기준 가락을 사용합니다. 마지막은 모든 소박을 직접 구성합니다.
3. **소리의 무대 · 3단계**: 공연 메모를 읽고 악기 편성·장단·음악 갈래를 조합합니다. 산조의 독주와 장구 반주, 시나위의 즉흥 합주 개념을 구분하며 마지막에는 편성과 박 구조를 함께 적용합니다. 복원한 편성이 실제 무대에 올라옵니다.

장단 공방은 악기 6단계 후, 무대는 장단 4단계 후 개방됩니다. 힌트와 도감은 단계별 학습을 돕습니다. 메뉴에서 복원 상태를 유지하며 다시 풀 수 있습니다.

## 공간과 조작

실제 국악박물관 사진의 어두운 진열장, 유리, 목재, 집중 조명을 참고한 가상 전시실입니다. 나뭇결·석재·직물·금속 재질, 곡면 출입구와 악기, 그림자, 진열장 조명을 코드로 제작했습니다. 실물 건축이나 유물을 정밀하게 복제한 모델은 아닙니다.

- PC: WASD/방향키로 걷기, 화면 드래그로 시점 이동, E 또는 전시 표식/조사 버튼으로 조사, Esc로 닫기·메뉴.
- 터치: 조이스틱·화면 드래그·조사 버튼. 퍼즐 패널은 아래에서 스크롤하며 위의 3D 전시를 계속 볼 수 있습니다.
- 퍼즐 중: 악기 후보를 고르면 해당 진열장으로 시선이 이동합니다. 3D 진열장을 직접 눌러 선택할 수도 있습니다. 장단은 소리 블록을 고른 뒤 패널의 빈칸 또는 3D 원형 장단판을 누릅니다.
- 이동 보조: 메뉴 → 전시실 이동. 설정에서 음소거·음량·이동 속도·시점 감도를 조절합니다.

진행과 설정은 현재 브라우저의 localStorage에 저장됩니다. v1 저장의 첫 세 악기 복원과 설정을 유지하고, 개편된 장단·무대는 새로 시작합니다. 재도전은 열린 공간과 기록을 보존합니다. 전체 초기화에는 확인 화면이 있습니다.

## 음악과 출처

- 악기 9종: 가야금·대금·해금·거문고·향피리·아쟁·징·꽹과리·장구.
- 실제 녹음 11개: 국립국악원 디지털음원 서비스의 공공누리 제1유형 자료. 장구는 덩·쿵·덕 세 녹음을 사용합니다. 총 2.1 MB 미만이며 원출처와 가공은 [음원 목록](public/audio/manifest.json)에 기록했습니다.
- 6개의 비교 합주와 3개의 무대 음형은 실제 단음을 재배열한 **교육용 창작 예시**입니다. 산조·시나위 등의 실제 악곡이나 연주 양식을 재현한 공연 녹음은 아닙니다. 정악용 악기 샘플을 민속악 전용 악기 녹음으로 설명하지 않습니다.
- 도감에서 정악·산조·시나위의 배경과 편성 원리를 읽고 원자료로 이동할 수 있습니다.
- 장단 가락은 학습용 단순화입니다. 같은 장단의 유일한 연주법으로 제시하지 않습니다. 세마치는 e-국악 예시, 나머지는 국립국악원에서 확인한 박 구조를 참고합니다. 휘모리는 2소박 4박형입니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `src/main.ts` | 메뉴·퍼즐 패널·입력·3D/오디오 연결 |
| `src/museum.ts` | 공간·재질·조명·악기 모형·이동·전시 복원·장단판 |
| `src/audio.ts` | 실제 녹음 로딩·합주 배열·장단·예약 취소 |
| `src/data.ts` | 악기·6+4+3 문제·음악 갈래·원자료 |
| `src/state.ts` | 저장 마이그레이션·진행·정답 검증·충돌 |
| `public/audio/manifest.json` | 녹음별 출처·권리·가공 기록 |
| `scripts/prepare-expanded-audio.cjs` | 추가 원본 WAV의 발췌·정규화 재현 |

검증: `npm test` 20개 통과, TypeScript와 프로덕션 빌드 통과. 브라우저의 전체 진행·3D 장단 입력·모바일 레이아웃은 [검증 기록](docs/verification.md)에 범위와 한계를 남겼습니다.
