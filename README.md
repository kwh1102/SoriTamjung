# 소리탐정 — 사라진 소리를 찾아서

한국음악 수업 과제 **‘국악을 일상으로’**를 위한 3D 국악박물관 퍼즐 게임. 설치·회원가입·게임 중 생성형 AI 호출 없이 실행되는 정적 웹 프로젝트입니다.

관객용 접속 주소: [소리탐정](https://sori-detective-museum.cherrypearl22.chatgpt.site). 공개 배포가 완료된 뒤 링크를 이용하며, 자세한 검증 범위는 아래 문서를 참고하세요.

## 실행

Node.js 22.12 이상(개발 환경: 22.18.0)에서:

```sh
npm ci
npm run dev
```

Local 주소(기본 `http://localhost:5173`)로 접속합니다. 휴대폰은 같은 Wi-Fi에서 터미널의 Network 주소를 사용합니다. 방화벽·네트워크에 따라 로컬 기기 접속은 제한될 수 있습니다.

```sh
npm test
npm run build
npm run preview
```

`dist/`를 정적 호스팅에 올리면 됩니다. 오디오 파일도 포함됩니다. file:// 직접 열기는 ES 모듈·fetch가 제한되므로 HTTP 서버를 사용하세요. 의존성은 `package-lock.json`으로 고정합니다. 공식 문서: [Vite](https://vite.dev/guide/), [Three.js](https://threejs.org/docs/pages/WebGLRenderer), [Web Audio 예약 재생](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/start).

## 플레이

1. 소리를 켜고 입장 → 로비의 빛나는 표식 조사.
2. 악기의 방 3문제: 가야금 단음 → 합주에서 대금 → 해금 찾기.
3. 장단의 방 2문제: 세마치 예시의 빈 소박 복원.
4. 공연장 차례 감상 → 발견의 기록으로 복원 완료.

PC: WASD/방향키, 화면 드래그 시점, E/가까운 표식 클릭/조사 버튼, Esc 닫기·일시정지. 터치: 조이스틱·화면 드래그·조사 버튼. 장단: 블록 선택 후 빈칸 클릭/터치, PC 끌어 놓기도 지원. **메뉴 → 전시실 이동**은 이동 보조입니다. 잠긴 공간은 해제 조건을 안내합니다.

메뉴 → 소리와 조작 설정: 음소거·전체 음량·속도·감도. 메뉴에서는 이동 중지, 닫기·탭 전환·포커스 상실 시 오디오 정지. 진행·설정은 브라우저 localStorage 저장(기기 간 동기화 없음). 초기화 전 안내가 있습니다.

## 화면 구성

시작 화면은 제목·짧은 설명·시작 버튼으로 구성합니다. 플레이 중에는 박물관이 화면 전체를 차지하고, 현재 목표와 지금 가능한 행동 하나를 표시합니다. 진행률·이동·도감·설정·출처는 메뉴를 열 때만 나타납니다.

퍼즐은 듣기부터 시작합니다. 필요한 예시를 들으면 선택지나 보드를 보여주며, 정답 후에는 복원 결과와 설명을 별도로 보여줍니다. 후보 악기는 버튼 하나로 듣고 선택합니다. 본문은 16~18px를 중심으로 하고 모바일 장단 보드는 박별 세 줄로 배치합니다. 기존 저장 데이터는 그대로 이어집니다.

## 콘텐츠

- 실제 녹음 6개: 국립국악원 정악가야금·정악대금·해금·장구 덩/쿵/덕, 총 약 882KB. 단음 서비스에서 악기별 공공누리 제1유형 확인. 발췌·모노 변환·정규화·페이드·미세조율은 manifest에 기록.
- 합주는 분리된 실제 단음을 같은 Web Audio 시간축에 배열한 **교육용 창작 예시**. 녹음에서 악기 제거를 하지 않으며 전통 악곡의 완성 합주 녹음이 아닙니다.
- 세마치: 3소박×3박, 한 칸=1소박. 국립국악원 e-국악의 ‘덩-- / 덩-덕 / 쿵덕-’. 유일한 연주법이라고 설명하지 않습니다.
- 마지막은 악기 단음과 장단의 **차례 감상**. 전체 전통 악곡 공연 음원은 미확보.
- Three.js로 직접 만든 **도식적 3D 모형**. 정밀 실물 복원이나 외부 이미지·생성 이미지가 아닙니다.
- Google Fonts(Noto Sans KR·Noto Serif KR·DM Sans, SIL OFL) 선택 로딩. 연결 실패 시 시스템 글꼴 대체.

## 구조 및 확장

| 파일 | 역할 |
|---|---|
| src/main.ts | HTML 메뉴·모달·퍼즐·접근성·조작 연결 |
| src/museum.ts | Three.js 공간·1인칭·충돌·조사·복원 |
| src/audio.ts | WAV 로딩·재생·예약·정지·음량 |
| src/data.ts | 문제·국악 설명·장단·출처 데이터 |
| src/state.ts | 저장 검증·진행·개방 규칙·충돌 판정 |
| public/audio/manifest.json | 실제 출처·이용 조건·가공 내역 |
| tests/game.test.ts | 저장·개방·충돌·실제 PCM 자산 검사 |

문제 추가 시 data.ts와 진행 상한을 함께 수정합니다. 음원 교체는 동일 ID를 유지하고 manifest와 출처 기록도 갱신하세요. 음높이·속도·길이·음량을 확인하고 청취 검수합니다.
