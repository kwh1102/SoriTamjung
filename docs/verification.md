- 악기/장단 오답 후 재시도·1단계 힌트·정답 해설·복원 전후 재생·음원 소스 화면 확인.
- 재생·정지·4회 반복 체크·다음 문제에서 이전 재생 및 표시가 정리되는 상태 확인. 취소와 겹침 방지 내부 동작은 자동 테스트로 보완.
- 100% 상태에서 새로고침 후 이어하기 표시·진행 복구 확인. 초기화 경고 → 0% 복구, 음량/속도 슬라이더 키 조작, 이후 다시 끝까지 진행 확인.

- 화면 증빙은 로컬 `.local/`에 저장하며 배포에 포함하지 않음.

## UI 개편 검증 (같은 날)

- 새 시작 화면과 전체 화면 탐험을 1280×800에서 확인. 상시 사이드바·대시보드·미리보기 카드 없음.
- 단음 문제는 단서 재생 후, 합주 문제는 완성/누락 두 예시 재생 후 후보가 나타남. 첫 예시만 들은 상태의 후보 수 0개를 브라우저 DOM으로 확인.
- 악기 오답 → 힌트 → 정답, 세 악기 문제 → 장단 두 문제 → 공연장 → 복원 결과까지 새 UI로 완주.
- 모바일 390×844에서 장단 보드는 3행으로 표시, 모달 폭 366px·높이 약 727px, 화면 밖 가로 넘침 없음. 844×390에서 전시실 메뉴 폭 660px이며 세로 스크롤 가능.
- 새 메뉴의 전시실 이동·설정·음소거 전환·초기화 경고 확인. 100% 완료 후 새로고침·이어하기·메뉴의 100% 복구 확인.
- 브라우저 콘솔 error/warn 없음. `npm test` 9개 통과, TypeScript 검사·프로덕션 빌드 통과.
- 실제 휴대폰 터치/청취와 사용자 대상 가독성 평가는 별도 미실시. 화면 단순화가 실제 이용자의 이해를 개선하는지는 관객 테스트에서 추가 확인 필요.
