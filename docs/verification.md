# 개편 버전 검증

검증일: 2026-11-19–20. 로컬 소스의 검증이며 기존 공개 사이트에 재배포했다는 뜻은 아닙니다.

## 자동 검사

`npm test`: 20개 통과. `npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과.

- 13단계 순차 진행·실물 전시 복원 목록·방 개방·진행률.
- 오염된 저장·잘못된 단계·중복 정답·선행 과제 미완료에서 진행 건너뛰기 방지.
- v1 저장의 첫 세 악기/설정 이전, 확장된 장단·무대 재시작.
- 두 악기 동시 정답의 누락·중복·추가 선택 거부.
- 편성·장단·갈래의 복합 정답 검증. 한 조건만 달라도 실패.
- 장단의 쉼·순서·길이와 시작점 회전 검증.
- 물리 벽·전시대·잠긴 통로 충돌 및 열린 이동 경로.
- 11개 WAV의 실제 PCM·표본률·채널·유효 진폭·2.1 MB 미만 크기, 출처와 파일 존재.
- AudioContext 절대 시점 예약·장단 반복 경계·재생 교체/닫기 취소.
- 합주에서 악기를 제거해도 남은 악기의 재생 시점 유지. 무대에 장구가 있을 때만 장구 반주 재생.

## 브라우저 검사

로컬 Vite 서버와 인앱 Chromium 브라우저에서 진행했습니다.

- 악기 6단계 → 장단 4단계 → 무대 3단계까지 전체 진행과 13/13 완료 확인.
- 오답으로 진행하지 않으며, 정답 시 진열장에 악기가 나타나고 공간이 차례대로 개방됨.
- 3D 원형 장단판의 앞쪽 타일을 직접 클릭해 패널 첫 소박이 덩으로 바뀜을 확인.
- 390×844 화면에서 위쪽 3D 영역·아래쪽 스크롤 패널·정답 버튼 접근 확인. 선택 후 스크롤과 초점 유지 보완.
- 마지막 무대의 편성·장단·갈래 선택, 일부 조건 오답, 전체 조건 정답과 무대 표시를 별도로 재검사.
- 진열장별 카메라 접근이 갤러리 내부에서 이루어지도록 수정. 관악기 지지대와 전시 라벨 비율 보완.

## 범위와 한계

실제 스마트폰 GPU·Safari·Firefox에서는 별도로 검증하지 않았습니다. 3D 그림자와 다수의 전시 조명은 저사양 기기에서 비용이 있으며 픽셀 비율은 1.5로 제한합니다. WebGL 시작 실패 시 전시실 선택과 패널로 퍼즐을 이어가는 안내를 제공합니다.

전공자의 청취·내용 검토와 신규 관객 난이도 조사는 미실시입니다. 20–30분은 기획상 예상 시간입니다. 음악은 실제 악기 단음을 배열한 학습용 창작 음형이며 전통 악곡의 완성 연주나 해당 갈래의 고유 양식을 재현한 녹음이 아닙니다.
