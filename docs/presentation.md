# 발표 시연 경로 (3~5분)

## 시작 전

- 공개 링크를 로그인하지 않은 브라우저로 확인하고 QR을 준비한다. 공개 승인 전 비공개 Sites 주소를 관객용 링크로 안내하지 않는다.
- 스피커·이어폰 음량 확인. 여러 관객이 동시에 재생하면 소리가 섞이므로 이어폰 또는 차례 듣기 권장.
- 설정에서 진행 초기화. 기기별 저장 독립. 네트워크 장애 대비 로컬 서버 준비.

## 시연

1. **20초 기획:** “국악 초보자도 귀로 차이를 발견하도록, 소리를 되찾는 탐정 게임을 만들었습니다.” 박물관 전체 보기.
2. **20초 탐험:** 소리를 켜고 입장, 이동·드래그·로비 조사. 현재 목표와 조사 버튼을 보여주고, 필요하면 메뉴 → 전시실 이동을 안내.
3. **60초 악기:** 단음·후보 듣기 → 오답 → 힌트 → 가야금 정답. 합주 완성/누락 비교, 대금·해금 복원. 실제 단음의 교육용 재구성임을 명시.
4. **60초 장단:** 세마치 9칸=3소박×3박 설명. 첫 빈칸 덩. 다음은 4칸 덩·6칸 덕·8칸 덕. 기준/내 배치·현재 소박 강조 시연.
5. **30초 복원:** 열린 공연장, 실제 단음 차례 듣기 → 발견의 기록. 문·표식·장치 움직임 변화.
6. **20초 과정:** 자산별 제1유형 확인·가공 기록·Web Audio 예약·정적 배포·저장 선택 설명.

## 마무리 초안

“서로 다른 악기의 소리를 비교하고 반복되는 장단을 직접 복원했습니다. 내가 채운 소리를 다시 듣는 작은 경험으로 국악을 일상에 연결하고 싶었습니다.”

본인의 경험·수업 학습을 바탕으로 수정할 것. 5분 목표의 실제 플레이타임과 관객 반응은 시연 후 추가.
