## 기획 의도와 대상

국악 지식이나 게임 경험이 많지 않은 대학생과 일반인이 이름을 암기하기 전에 실제 악기 소리를 비교하고 빠진 부분을 채우도록 기획했다. 관객은 설치나 계정 없이 웹으로 접속한다. 박물관 소리 장치가 고장 났다는 짧은 사건 속에서 플레이어는 ‘소리탐정’이 된다. 음악 시험의 점수보다 귀를 기울여 공간을 되살리는 성취감을 중심에 두었다.

## 국악 요소

정악가야금·정악대금·해금의 실제 단음을 활용한다. 줄을 뜯는 가야금, 대나무 관을 가로로 불고 청이 진동하는 대금, 두 줄 사이 활을 움직이는 해금을 비교한다. 소리의 시작·지속·감쇠에 집중한 뒤, 같은 짧은 음형의 합주에서 빠진 악기를 복원한다. 악기별 분리 녹음이므로 합주 녹음에서 악기를 자동 제거하지 않는다.

장단은 국립국악원 e-국악의 세마치 예시 ‘덩-- / 덩-덕 / 쿵덕-’를 사용한다. 9칸은 각 1소박이며 3칸씩 묶어 3박을 표시한다. 덩은 장구 양편, 쿵은 궁편, 덕은 채편과 연결한다. 첫 문제는 빈칸 하나, 다음은 세 칸을 채운다. 이 예시가 유일한 세마치 연주법이라는 오해를 피하도록 설명한다.

## 구성과 이용

로비에서 사건·소리를 확인하고, 악기의 방 3문제를 풀면 장단의 방이 열린다. 장단 2문제를 해결하면 공연장이 복원된다. 마지막에는 단음과 장단을 차례로 듣고, 복습 카드와 도감을 확인한다. 전체 전통 악곡은 확보하지 않아 ‘작은 소리 전시’로 명시했다. 약 5분을 목표로 하되 관객 시연에서 실제 시간을 측정·조정한다.

PC는 WASD/방향키, 화면 드래그, E/클릭으로 탐험한다. 터치는 조이스틱·드래그·조사 버튼을 사용한다. 공간 메뉴는 전시물 앞으로 이동하는 보조 기능이다. 음량·이동 속도·감도 설정, 무제한 다시 듣기, 단계별 힌트, 구체적인 오답 안내를 제공하고 시간제한·탈락은 없다. 브라우저에 진행을 자동 저장한다.

## 제작과 확인

Vite·TypeScript·Three.js의 정적 앱으로 구현하고 Web Audio 시간축에 소리를 예약했다. 한지·목재·절제된 색감의 공간과 도식적 악기 모델을 직접 제작했다. 실제 단음은 파일별 이용 조건을 확인하고 발췌·모노 변환·정규화·페이드·미세조율을 기록했다. 저장 상태·개방·충돌·음원 검사를 수행하고 브라우저 및 실제 기기 검증 범위는 별도 기록한다.
